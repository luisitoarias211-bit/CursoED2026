# Sistema de Gestion del Terminal Portuario Turistico de Buenaventura
El **Sistema de Gestión del Terminal Portuario Turístico de Buenaventura** es una aplicación desarrollada en el lenguaje de programación C que tiene como finalidad optimizar y organizar los procesos básicos de operación de un terminal marítimo turístico. El sistema está diseñado para administrar de manera eficiente el registro de destinos, el control de pasajeros, la programación de viajes y el proceso de embarque, haciendo uso de estructuras de datos dinámicas y algoritmos eficientes para el manejo de la información.

# Objetivos

## Objetivo General

Diseñar e implementar un sistema que permita administrar el funcionamiento del Terminal Portuario Turístico de Buenaventura utilizando estructuras lineales y no lineales mediante apuntadores.

## Objetivos Específicos

- Registrar destinos turísticos de manera dinámica.
- Gestionar pasajeros mediante colas FIFO.
- Registrar viajes programados utilizando árboles balanceados.
- Controlar el proceso de embarque.
- Consultar información de pasajeros y destinos.
- Generar estadísticas del sistema.
