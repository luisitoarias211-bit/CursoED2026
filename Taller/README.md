# Software De Agendamiento De Cita De Un Hospital

En el lenguaje C desarrollaremos una aplicación para gestionar el registro y la atención de pacientes en un hospital. El sistema almacenará únicamente el número de documento de cada paciente y registrarlo en una cola de atención. Los pacientes serán llamados y atendidos respetando el mismo orden en que fueron ingresados al sistema, de acuerdo con el principio FIFO.
Después de atender a cada paciente, el médico deberá registrar su número de documento y clasificar su estado de salud como sano, enfermo o grave. Estos registros deberán almacenarse en una pila de diagnósticos, de manera que el último diagnóstico registrado sea el primero en consultarse o procesarse, aplicando el principio LIFO. De esta forma, la cola organizará la atención de los pacientes y la pila permitirá administrar los resultados obtenidos después de cada consulta.
