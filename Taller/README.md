# Software De Agendamiento De Cita De Un Hospital

Un software donde se gestionara citas medicas de un hospital, utilizando una cola organizar la atencion de los pacientes segun su orden de llegada y una pila para almacenar los diagnosticos de cada paciente despues de cada cita
